A deadpan one-star review of an everyday essential: gravity. It files a
sincere complaint against a force that cannot be fixed, stays perfectly
straight-faced, and saves its sting for the last few words. The program
writes the review, one line of at most 160 characters, to `entry.txt`.

## Run it

```sh
python3 main.py
```

By default the review is written to `/output/entry.txt`. To write it
somewhere else, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program validates the review first (UTF-8, 1 to 160 characters, a
single line, not only whitespace) and prints the character count.
